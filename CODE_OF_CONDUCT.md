# Code of conduct

Treat contributors respectfully. Critique ideas and code constructively, welcome
questions, and respect people's privacy and boundaries.

Harassment, discrimination, threats, personal attacks and publication of private
information are unacceptable in project issues, pull requests and discussions.

Report concerns privately to akshay.anu@gmail.com. The maintainer will review reports
discreetly and may remove content, restrict participation or block accounts when
needed to protect the community.
