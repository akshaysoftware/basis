# Basis

Basis is a typed language and interpreter for small hybrid classical and quantum
programs. It combines classical control flow with explicit qubits, gate operations,
measurement and local statevector simulation in a C++20 toolchain.

The current development priorities are simulator correctness, reproducible sampling,
clear diagnostics and a well-defined circuit-export contract.
See [known issues](known-issues.md), [getting started](getting-started.md) and
[the language specification](language-spec.md).
